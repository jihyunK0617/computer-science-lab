# 💻 Computer Science Lab

A repository for reviewing and strengthening my **computer science fundamentals** through notes, implementations, and experiments.

Rather than simply documenting theoretical concepts, I aim to understand how they work by implementing, testing, and connecting them to real-world software systems.

* File System

## 🧪 Learning Approach

For each topic, I try to follow:

**Concept → Implementation → Experiment → Analysis → Application**

For example:

```text
Race Condition
      ↓
Reproduce with Code
      ↓
Mutex / Semaphore
      ↓
Compare Behavior
      ↓
Connect to Backend Concurrency
```
